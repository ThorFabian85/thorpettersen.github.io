# Forbidden Grand Narrative website

A static website for **Forbidden Grand Narrative: The Story Humanity Was Told Not to Remember** by Thor Fabian Pettersen.

## Publish free with GitHub Pages

1. Create a free GitHub account at github.com.
2. Create a new **public** repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your exact GitHub username).
3. Upload **everything inside this folder** to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Your site will be available at `https://YOURUSERNAME.github.io/`.

No paid domain is required.

## Files
- `index.html` — homepage + searchable table of contents
- `reader.html` — full embedded PDF reader
- `chapters/` — one linkable page per chapter/front-matter section
- `forbidden-grand-narrative.pdf` — original book
- `cover.png` — homepage cover image
- `style.css` / `script.js` — design and chapter search
